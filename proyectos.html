Solución: Interfaz web para clientes con lógica de agendamiento conectada a base de datos y contacto directo vía WhatsApp con la administración.

Business Intelligence Power BI

Dashboard Ejecutivo: Entorno Empresarial

Problema: Datos complejos del entorno empresarial chileno difíciles de interpretar para la toma de decisiones.
Solución: Modelo analítico con KPIs globales, análisis de oportunidades y nichos de mercado, y tablas operacionales filtrables por tramos y años comerciales.

Stack: Power BI, Power Query, Modelado de Datos
Control Financiero Looker Studio

Control Financiero y Presupuestario

Problema: Necesidad de registrar, auditar y controlar en tiempo real el gasto real frente a lo presupuestado por categoría.
Solución: Aplicación web en Apps Script para registro de transacciones conectada a Google Sheets y a un dashboard en Looker Studio para auditoría y análisis de presupuesto en tiempo real.

Stack: Looker Studio, Google Apps Script, Google Sheets
